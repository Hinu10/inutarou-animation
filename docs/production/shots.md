# ショットの書き方（アニメーション実装）

第1話はすべて**仮素材（TEMP）**で実装済み（`cuts.toml` の status = `temp`）。正式素材ではないので完成ではない。

## ショットとカットの関係

| ショット（`scenes/episode01/shots/`） | カット | 尺 | 内容 |
| --- | --- | --- | --- |
| `s1_potechi.py` | s1c01〜s1c02 | 0〜8秒 | ポテチを置く／トイレへ |
| `s2_karasu.py` | s2c01〜s2c03 | 8〜16秒 | カラスの侵入・持ち去り・「何だあいつ」 |
| `s3_argument.py` | s3c01〜s3c06 | 16〜30秒 | 言い合い・一時停止ナレーション・「ワン！」 |
| `s4_window.py` | s4c01〜s4c03 | 30〜41秒 | 窓を指さす・吠えてると思われる・地団駄 |
| `s5_crow.py` | s5c01〜s5c03 | 41〜49秒 | 窓の外のカラス・「悪かったな」 |
| `s6_card.py` | s6c01〜s6c04 | 49〜55秒 | 財布・カード・課金通知 |
| `s6_ending.py` | s6c05〜s6c09 | 55〜60秒 | 試作（グッドサイン → アッパー） |

`_common.py` はショットではなく共通の準備（部屋・役者の配置・吠え声の文字・汗など）。

ショットは `cuts.toml` の `shot = "..."` で結びつく。ショットのスクリプトに書くのは
「カットの頭から何コマ目に何をするか」だけで、カットの長さ・カメラ・セリフの位置は `cuts.toml` から読む。
セリフの頭（`common.line(cut, "kaito").frame`）に合わせて口パクや表情を入れているので、
`at` を動かせば演技もついてくる。

## 部品

| 場所 | 中身 |
| --- | --- |
| `lib/inutarou_anim/actor.py` | `Actor`（全ボーンをまとめてキー）、`P`/`merge`（姿勢の書き方）、`at`（置く位置）、`Actor.reach`（腕の IK） |
| `lib/inutarou_anim/motions.py` | 汎用モーション: `walk`（歩き）、`game`（ゲーム操作）、`flap`（羽ばたき）、`talk`（仮の口パク）、`blink`、`tremble`、`bounce`、`look` |
| `assets/props/items.py` | 小道具の形（ポテチの袋・かけら・スマホの画面・通知・カード） |
| `assets/backgrounds/apartment_room.py` | 部屋。机・ドア・窓の手前の枠（`window_front`）を追加。`SPOTS` が置き場所 |

キャラクターごとの姿勢の数値（例: ゲーム操作の腕の角度）は `design.py` の `MOTION` に置き、
`motions.py` はそれを読む。正式デザインに替えても、`MOTION` を合わせればショットはそのまま動く。

## 演出上の決めごと（仮）

- **テレビはカメラの側**にある想定。犬太朗は画面のこちらを見てゲームをしている（正面向きの仮キャラのため）。
- 犬太朗のセリフは視聴者には日本語。海斗の視点のカット（s3c06・s4c02）でだけ「ワン！」の文字を出して、人間にはこう聞こえていると見せる。
- s3c05 の一時停止は、暗く沈めた止め絵＋一時停止マーク＋帯テロップ。ナレーションの長さは `cuts.toml` の秒数で調整。
- 窓の外のカラス（s5）は、背景と窓の手前の枠の間に置いてガラスの向こうに見せる。

## 足りないところ（仮素材の限界）

- キャラが正面向きのまま横に歩く（振り向き・横向きの絵が無い）。脚は1本の骨で曲がらない。
- 口パクは文字数から長さを見積もった仮のもの。音声に合わせる仕組みは Codex（#46）。
- 表情の中割りが無いので切り替えがパッと変わる。
- 歩きは足の振り＋上下動だけ。地面との接地（足が滑る）は合わせていない。
