## 試作で達成した品質と、足りないところ

**仮素材の試作であり、テレビアニメと同じ品質ではない。**

| 項目 | 今の状態 | 足りないところ |
| --- | --- | --- |
| キャラクターの見た目 | 仮デザイン（図形の組み合わせ） | 正式デザインが無い。線に強弱や手描きの味が無い |
| 体の動き | 骨のキー＋2コマ打ち。ため・行き過ぎ・戻りは入れた | 体が正面向きのまま横に歩く。振り向き・横向きの絵が無い。脚は1本の骨で曲がらない |
| 表情 | 目・口・眉の描き替え（犬太朗: 怒り・驚き・ジト目・ぼやき、海斗: ジト目・点目・困り眉・気まずい笑い などを追加） | 中割りが無いのでパッと変わる。口パクは文字数から見積もった仮（音声連動は #46） |
| ギャグの変形 | 顔パーツ全体に同じ変形をかけて連動 | 変形は 2段階だけ。作画監督が描くような「崩し顔」の描き込みは無い |
| 撮影効果 | フラッシュ・揺れ・集中線・衝撃背景 | 色の調整・ボケ・質感（紙の質感など）は無い |
| 音 | 仮（機械の声・合成音） | 正式な声・効果音・BGM が無い。犬の鳴き声（人間側の聞こえ方）の演出も未定 |
| 60秒の本編 | 全カットを仮素材で実装（temp） | オーナーのチェック前（#40）。タイトル・クレジットは内容待ち（#57） |

画面左上に `TEMP ASSETS / PROTOTYPE`、左下にカット名とフレーム番号を焼き込んでいる（仮であることの表示）。
