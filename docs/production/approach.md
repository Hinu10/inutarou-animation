# 制作方式の比較と決定

## 結論

**Blender 5.2 + Grease Pencil v3 を Python で組み立てる方式**を採用する（指示書の第一候補どおり）。

## 比較

| 観点 | Blender + Grease Pencil（採用） | Python で直接描画（Pillow / cairo） | OpenToonz / Synfig |
| --- | --- | --- | --- |
| この Mac に入っているか | ○ 5.2.3 LTS あり | ○（cairo は無し） | × 未インストール |
| パーツを骨で動かす | ○ アーマチュア＋レイヤーの親子付け | △ 自前で全部書く | ○ |
| 表情・手の差し替え | ○ GP のフレーム＝描き替え | △ 自前 | ○ |
| ギャグの大げさな変形 | ○ 頂点を直接ゆがめた描き替えを Python で作れる。手で描き直すこともできる | ○ | △ |
| Python から全部作れるか（Codex と分担しやすいか） | ○ `bpy` で完全に再現できる | ○ | △ スクリプト API が弱い |
| 人が手で直せるか | ○ 生成された .blend を開いて描き足せる | × | ○ |
| 再現性 | ○ 同じコマンドで同じ絵 | ○ | △ |

Python 直描きは軽いが、正式デザインが来たあとに「人が Blender で描き直す」道が無くなる。
OpenToonz は手描きには強いが、コードでの組み立て・自動化に向かない。
Grease Pencil は両方（コードで組む／人が描き足す）ができるのが決め手。

## 仕組みの要点

- **1キャラクター = アーマチュア 1つ + GP オブジェクト 1つ。GP のレイヤー 1枚 = パーツ 1つ。**
  レイヤーはボーンに親子付けしてあり、首・手足・目線はボーンのキーで動く。
- **表情や手の形は描き替え。** 各パーツに variant（例: 目 = default / smug / closed / squeeze / spark）を持たせ、
  `rig.swap(フレーム, パーツ, variant)` で GP のフレームを置く。
- **ギャグの変形は「ゆがめた描き替え」。** 顔まわりのパーツ（FACE_PARTS）すべてに同じ warp
  （`dent_warp` = 拳がめり込む、`inflate_warp` = 押された肉が盛り上がる）をかけた絵をそのコマに置く。
  輪郭・ほお・目・口・耳が同じ変形で動くので連動する。
- **タイミングはアニメらしく 2コマ打ち。** なめらかにキーを打ってから、カットごとに Stepped 修飾子で 2コマ打ちに落とす。
  インパクト前後だけ 1コマ打ち。
- **カット表がデータ。** 秒数・セリフ・効果音・カメラ位置は `scenes/episode01/cuts.toml`。
  開始位置は長さの合計から決まるので、1カットの長さを変えれば後ろが自動でずれる。

## Blender 5.2 で分かったこと（つまずきやすい点）

- GPv3 のストロークは `fill_id` を 1 以上にしないと塗られない。同じ番号のストロークは 1つの塗り（穴あき）になる。
- `add_strokes` で作った点は `opacity` が 0 のことがある。
- レイヤーの親子付けは代入した時点の姿勢を基準にする（`matrix_parent_inverse` は読み取り専用）。
- Blender の文字オブジェクトは GP より奥に回るので、文字は輪郭を取り出して GP で描く（`stage.Text`）。
- Stepped 修飾子は `frame_end` を先に入れないと `frame_start` が切り詰められる。
