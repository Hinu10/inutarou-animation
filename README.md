# 犬太朗 (inutarou-animation)

オリジナル短編2Dアニメ『犬太朗』の制作リポジトリ。

| 項目 | 内容 |
| --- | --- |
| 第1話 | 消えたポテチ（日常系ドタバタギャグ） |
| 尺 | 約60秒 |
| 画面 | 16:9 / 1920×1080 / 24fps |
| 出力 | MP4（H.264） |
| 制作方式 | Blender + Grease Pencil + Python（第一候補。選定は下のタスク 1-2 で確定） |
| 環境 | macOS / Apple Silicon |

> 現在は立ち上げ段階です。キャラクターデザインは未確定で、当面は**仮素材**で制作します。仮素材の映像を完成品質として扱いません。

---

## 担当の分け方

| 担当 | 主な役割 |
| --- | --- |
| **オーナー（人）** | 企画・脚本の判断、正式キャラクターデザイン、声・SE などの素材、試作のチェックと OK 出し |
| **Claude Code** | 制作方式の選定、プロジェクト構造、キャラクターのリグ・パーツ構成、アニメーション実装（演技・表情・ギャグ演出） |
| **Codex** | ビルド・レンダリングの自動化、品質チェック、音声同期、CI |

### 編集してよい場所（同じファイルを同時に触らないため）

| 場所 | 主担当 | もう一方の扱い |
| --- | --- | --- |
| `scenes/`、`assets/characters/` のリグ、アニメーション用スクリプト | Claude Code | Codex は読むだけ。直したいときは Issue で依頼 |
| `scripts/render/`、`scripts/qc/`、`tests/`、CI 設定 | Codex | Claude Code は読むだけ |
| カット表などのデータ（秒数・セリフ・素材・カメラ） | 共有 | 作業前に Issue で担当を宣言してから触る |
| `assets/` の正式素材、`docs/characters/` の設定 | オーナー | AI は差し替え手順に沿って組み込むだけ |

運用ルール（案）
- 作業ごとにブランチを切り、`claude/…` `codex/…` の名前で区別する。`main` へは PR でマージする。
- 1つの作業ごとに1コミット（または1 PR）に分ける。
- 着手前に Issue を立てて担当者を書く。担当者が付いている Issue のファイルは触らない。
